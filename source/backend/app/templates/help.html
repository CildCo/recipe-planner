系统 · 使用说明

从一道菜开始

这个小程序只做三件事：看菜谱、排一周菜单、生成买菜清单。

01

本地跑起来

在 source/ 下执行：

python -m pip install -r requirements.txt
python start.py

打开 http://127.0.0.1:8020/admin。首次启动的密码在 backend/runtime/admin-password.txt。

02

连上小程序

用微信开发者工具打开 miniprogram/。默认是本地演示模式，不连后端也能点；要连后端时，把 config/index.js 里的 mode 改成 server，并把 apiBaseUrl 指向这台机器。

真机调试需要 HTTPS 域名；开发者工具里可以勾选“不校验合法域名”。

03

维护菜谱

“新建菜谱”里填菜名、食材、步骤和封面。食材的用量写成数字，生成清单时会自动相加；写“适量”就原样保留。

封面统一 1200×900，上传后会自动裁成 4:3。

04

一周菜单怎么排

小程序“菜单”页按周排，早、午、晚都能放多道菜。点“+”，从菜谱里选一道，设好人份。

“清单”页会把这周所有菜的食材合并；同类同单位的会相加。买完一项就勾掉。

05

家庭共享

每个账号第一次登录会自动建一个饭桌，并生成 6 位邀请码。家人在“我的 → 饭桌”输入邀请码，就能看到同一份菜单和清单。

06

上线前

把 APP_ENV=production、管理员密码、密钥、小程序 AppID 和 AppSecret 写进 backend/.env；用 MySQL 时改 DATABASE_URL；把 miniprogram/config/index.js 的接口地址换成 HTTPS 域名。

完成后先跑 python run_all.py，再打体验版。
